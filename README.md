What is Errandly?

Errandly is a multi-service platform designed to connect customers with reliable services such as laundry, errands, pickups, deliveries, and other everyday tasks.
Features:
✓ Customer registration and authentication
✓ Laundry ordering
✓ Order tracking
✓ Admin dashboard
✓ Staff assignment
✓ Errand requests
✓ Notifications
✓ Role-based access control
